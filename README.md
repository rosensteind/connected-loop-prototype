# The Connected Loop — prototype

A working prototype of a shared-visibility system for pastoral support, built
from a proposal by Farnaz Al-Sadi (Eton College, June 2026).

- **`index.html`** — what it is, who it is for, and what it deliberately is not
- **`demo.html`** — a five-minute walkthrough of six roles around one pupil
- **`policies.html`** — what happens to what you write, in two registers

**Everything in it is fictional.** Three invented pupils and an imagined
fortnight. No real pupil's information has ever been in this system.

It is not a diagnostic tool, not a treatment, not a monitoring system and not
an emergency service. Nothing in it screens, scores or classifies a child.

The working system — server, access-control tests, and the UK data protection
position — is held privately.

Built by Dr David Rosenstein, Clinical Psychologist.
