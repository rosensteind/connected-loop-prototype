# The Connected Loop — prototype

A working prototype of a shared-visibility system for pastoral support,
built from a proposal by Farnaz Al-Sadi (Eton College, June 2026).

**Everything in it is fictional.** Three invented pupils and an imagined
fortnight. No real pupil's information has ever been in this system.

## What it is

A way for the adults already responsible for one child to share what they each
already see. Six roles, each with a genuinely different view of one record.

## What it is not

Not a diagnostic tool, not treatment, not monitoring, and not an emergency
service. Nothing in it screens, scores or classifies a child.

## This repository

Contains only the prototype, as one self-contained page for demonstration.
The working system — server, access-control tests, and the data protection
position — is held privately.

Built by Dr David Rosenstein, Clinical Psychologist.
